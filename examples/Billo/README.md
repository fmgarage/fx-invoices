# Beispiel: Billo

Billo.fmp12 muss sich im selben Verzeichnis wie FX_Invoices.fmp12 befinden. **Billo**  öffnen und auf den *Erstellen*-Button klicken. 

Das Beispiel zeigt, wie einfach es ist, **FX  Invoices** zu implementieren: JSON mit allen Rechnungsparametern einschließlich PDF und Einstellungen übergeben und das kombinierte PDF bzw. die XML-Rechnung aus dem Ergebnis übernehmen.

Wie man das JSON in einer vorhandenen Rechnungsdatei erstellt, zeigt das **Starter**-Beispiel.
